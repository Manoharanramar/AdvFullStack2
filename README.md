# 📚 EduSync – Student Planner and Academic Organizer

EduSync is a full-stack web application designed to help students organize their academic activities efficiently. It provides a centralized platform to manage notes, assignments, tasks, and study schedules, improving productivity and time management.

---

## 🚀 Features

- 🔐 User Authentication (Sign Up & Login)
- 📝 Create, Edit, and Delete Notes
- 📅 Task and Assignment Management
- ⏰ Deadline Tracking
- 📖 Subject-wise Note Organization
- 📱 Responsive User Interface
- ☁️ Cloud Database Integration
- 🔍 Simple and Intuitive Navigation

---

## 🎯 Problem Statement

Students often use multiple applications or notebooks to manage notes, assignments, and schedules. This makes it difficult to stay organized, resulting in missed deadlines and reduced productivity.

---

## 💡 Solution

EduSync provides a centralized academic organizer where students can securely manage notes, assignments, and daily tasks in one place. The application simplifies academic planning and improves time management through an easy-to-use interface.
